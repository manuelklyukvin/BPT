# BPT

A small Android app that helps students find their way around the college - search for a classroom by number or name, filter by building and floor, and quickly jump to the school's site, VK group, e-diary, distance learning portal and class schedules.

This was one of my first real projects, made while learning Android development, so don't expect anything fancy - just plain Java, XML layouts and a bundled SQLite database with the room list.

## What it does

- Search classrooms by number or by name
- Filter results by building and floor
- Quick links to: college website, VK, e-diary, distance learning site
- Quick links to the class and break schedules

## Tech

- Java, Android SDK (min 27, compile/target 33)
- AppCompat + Material Components
- SQLite via SQLiteAssetHelper (the room database ships inside the app)
